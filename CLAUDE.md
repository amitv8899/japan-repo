# Japan trip vault

## Always
- At the start of every chat, read `must to be noted.md` and tell the user what is still open there (short list, most urgent first, with dates). If it has no open items, say so in one line.
- When you find something the user must check, verify, book or decide (mismatched times, missing bookings, deadlines, closed places), add it to `must to be noted.md` in the same pass and mention it.
- When an item is resolved, tick or remove it in `must to be noted.md`.
- Edit data via the `trip-edit` skill; read via `trip-fetch`.
